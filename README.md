# 🐍 Enable GitHub Snake Animation

Create:

```text
.github/workflows/snake.yml
```

and add:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"

  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest

    permissions:
      contents: write

    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: sivanssingh
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Publish Snake
        uses: crazy-max/ghaction-github-pages@v4
        with:
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

After the GitHub Action runs, your contribution snake will be available here:

```text
https://raw.githubusercontent.com/sivanssingh/sivanssingh/output/github-contribution-grid-snake.svg
```
